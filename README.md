# 📊 Student Marks Analyzer Using NumPy

A Python-based project that analyzes student performance using NumPy and Matplotlib. It generates marks for 50 students across 5 subjects and performs various statistical analyses to evaluate academic performance.

## 🎯 Project Objectives

- Generate random marks for 50 students across 5 subjects.
- Calculate total and average marks.
- Identify overall and subject-wise toppers.
- Find students scoring below 40 marks.
- Identify students scoring above 90 marks.
- Classify students into different grade bands.
- Calculate the overall pass percentage.
- Visualize subject-wise average marks using graphs.

## 🛠️ Technologies Used

- Python
- NumPy
- Matplotlib
- Google Colab

## 📚 NumPy Concepts Covered

- Array Creation
- Array Shape, Dimensions, Size and Data Types
